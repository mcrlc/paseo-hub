Reading: the only client-facing reader is SpritesSettings.snapshot, which returns Object.keys(env).sort() as envKeys.
setEnv/removeEnv discard the returned record; the server functions respond {state: "complete"}. activation.ts reads
the configuration for token and memoryMb only; triggers/store.ts checks presence only. Failures go through
respondWithFailure with fixed fallback strings or the SpritesEnvInputError message, which never includes the value.
